# University course-selection report template

Begin with:

> 本方案基于以下材料生成：……

## 1. Plan overview

| Plan | Positioning | Term | Total credits | Daily load | Status |
|---|---|---:|---|---|
| A | 稳妥达标型 | | | |
| B | 均衡发展型 | | | |
| C | 学术提前型 | | | |

## 2. Detailed course tables

For every section include: course code/section, course name, credits, course nature, teacher, exact weekday/period/weeks, room/campus, eligibility/enrollment remarks, source locator, and `待确认` labels.

## 3. Credit audit

Show total credits and each relevant curriculum module, with source values and arithmetic.

## 4. Validation

Report weekly conflicts, odd/even-week conflicts, online/laboratory conflicts, exam-time conflicts, enrollment-scope checks, and unresolved items.

## 5. Decision support

State advantages, disadvantages, risks, alternatives, default assumptions, and a separate `需要人工核实` section.
