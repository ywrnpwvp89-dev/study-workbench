# Official-source retrieval guide

Give retrieval instructions only after identifying the institution and program. Verify each URL before presenting it.

## Suggested discovery order

1. institution or college teaching-affairs office;
2. official curriculum/major-program search;
3. official academic-affairs notice or enrollment guide;
4. authenticated student enrollment system for selectable sections;
5. official timetable, catalog, academic calendar, and exam schedule.

## Retrieval advice

- Search the official domain using the exact major name, cohort, academic year, and term.
- Prefer pages or downloads that state version, publication date, applicable cohort, and issuing office.
- If a portal requires login, tell the student where to click but do not request credentials or bypass MFA/CAPTCHA.
- If a page is dynamic, inaccessible, or only visible after login, mark its facts `待确认` and request a redacted screenshot/export.
- Treat third-party forums and student spreadsheets as leads only, never as authoritative proof.

## What to provide to the student

For every requested item, state the official portal/page name, navigation path, expected file or fields, and a fallback such as a redacted screenshot or exported table. Never invent a download link.
