# 已验证偏好与边界

此工作流依据多轮活动回顾精修记录提炼，不包含聊天全文、素材、工程内部ID或私人路径。

- 一致性：新增照片沿用前面已批准的样式；不要随段落改变视觉语言。
- 时长：以当前音乐和目标片长协调段落；特定片段20—25秒、五分钟总长等仅是既往项目参数。
- 取舍：用户可以指定某类活动占比更高，不能把所有活动机械等分。
- 竖图：同活动双竖图并排、保持原比例；标题要明显、停留足够。
- 声音：现场声独立保留且避免重复，默认不主动给人声做BGM压低。
- 歌词：右上横排、白字黑影、手写字体为一个已使用方案，不自动套用所有项目。
- 工程：交付真实可编辑工程并说明外置盘依赖，不能只交视频或把快照冒充工程。

这些是工作流偏好而非素材授权；公开案例须采用自制或已获许可素材。
